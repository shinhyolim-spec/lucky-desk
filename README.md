# 럭키데스크 사주책상

직장인을 위한 오늘의 운세 웹앱. 아침에 열면 오늘의 점수와 해석이 바로 뜨고, 쉬는 시간엔 부적 긁기와 문구류 블록 맞추기를 할 수 있어요.

## 기능
- **한 번만 입력**: 양력 생년월일과 태어난 시간(모르면 생략)을 브라우저 `localStorage`에만 저장. 서버 전송 없음.
- **만세력 해석**: 오늘 일진과 내 일간의 십신 관계, 천간합·천간충, 일지 기준 충·육합·반합·형·해·파, 띠 충.
- **오늘의 점수(100점)**: 십신 관계 + 신강/신약 간이 판정 + 합·충 가감점. 같은 날 같은 사람은 항상 같은 점수.
- **행운 추천**: 그날 도움이 되는 오행에서 색·액세서리·문구류·숫자.
- **부적 긁기**: 문질러서 오늘의 한마디 확인.
- **블록 맞추기**: 8×8, 한 판 3분(첫 이동에 시작, 다른 화면에 가면 일시정지). 볼펜·포스트잇·클립·연필·지우개·압정. 오늘의 행운 색 블록은 블록당 +15 보너스, 연쇄 시 배율 증가.
- **PWA**: 홈 화면에 추가하면 앱처럼 실행, 오프라인에서도 열림.

## 계산 방식과 한계
- 일주: 율리우스 적일 기반 60갑자 순환 (2000-01-01 = 戊午일 기준 검증)
- 년주·월주: 태양 황경으로 절기 계산 (입춘 315°, 이후 30°마다 절입). 오차 수 분 수준.
- 시주: 한국 표준시 대비 태양시 30분 보정 (자시 23:30~01:30). 23:30 이후 출생은 다음 날 일주로 계산.
- **음력 입력은 지원하지 않아요.** 양력으로 변환해서 입력해야 해요.
- 1948~1988년 일부 서머타임 기간은 자동 보정하지 않아요.
- 신강/신약은 오행 가중치로 본 간이 판정이라, 전문 명리 해석과 다를 수 있어요.

## 구조
```
index.html            화면
css/style.css         디자인
js/saju.js            만세력 (일주·절기·시주, 합충형해)
js/fortune.js         점수·해석 문구·행운 아이템·부적 문구
js/scratch.js         부적 긁기
js/match3.js          블록 맞추기
js/icons.js           문구류 SVG
sw.js, manifest.webmanifest, icons/   PWA
tests/                node 테스트 (node tests/saju.test.mjs)
```
빌드 도구 없이 정적 파일만으로 동작해요.

## 로컬 실행
```
python3 -m http.server 8000
# http://localhost:8000
```

## 배포 (GitHub Pages)
1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: 기본 브랜치 / `(root)` 선택 후 Save
3. 1~2분 뒤 `https://shinhyolim-spec.github.io/lucky-desk/` 에서 열림

파일을 수정해 다시 배포할 땐 버전 숫자를 함께 올려 주세요: `sw.js`의 `VERSION`, `index.html`과 각 `js/*.js` import의 `?v=` 값. 그래야 이미 열어 본 휴대폰에서 새 화면과 예전 코드가 섞이지 않아요.

## 홈 화면에 추가

- 안드로이드(Chrome): 메뉴 ⋮ → 홈 화면에 추가 / 앱 설치
