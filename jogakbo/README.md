# 일상의 조각보

질문 하나에 답하면 조각 하나가 생기고, 30조각이 모이면 전통 조각보가 완성되며 '나에 대한 이야기'가 나타나는 자아찾기 웹앱.

- 회원가입·서버 없음. 모든 기록은 이 기기 브라우저(`localStorage`, 키 `jogakbo.v1`)에만 저장
- 휴대폰 화면 기준, 홈 화면에 추가하면 앱처럼 실행(PWA), 오프라인에서도 열림
- 주소: `https://shinhyolim-spec.github.io/lucky-desk/jogakbo/`

## 화면
- **조각보**: 빈 조각보 틀 → '오늘의 조각 하나 채우기' → 질문 1개·선택지 4개(+선택 메모) → 조각이 살포시 붙음
- **완성**: 마지막 조각이 붙으면 조각보가 완성되고 결과가 천천히 나타남 (한 문장 / 소중히 여기는 것 / 필요한 것 / 건네는 한마디)
- **옷장**: 완성한 조각보가 개어져 쌓임. 횟수 제한 없음. 두 장을 골라 나란히 비교(성향 비율 변화, 달라진 대답)
- **전시장**: 옷장에서 꺼내 벽에 건 조각보와 캡션(날짜, 그때의 한 문장)
- **공유**: 조각보+결과를 이미지로 만들어 공유(지원 안 되는 브라우저는 내려받기/길게 눌러 저장)

## 고치기 쉬운 데이터 파일
- `data/questions.json` — 질문 은행. 질문 추가는 `questions` 배열에 같은 형식으로 덧붙이면 끝 (조각 수 = 질문 수, 배치는 자동)
  - `tags`: 성향별 조각 색. `categories`: 갈래(일상·일·관계·마음·쉼·꿈)
  - 선택지 순서(1~4번째)에 따라 조각 무늬가 달라짐: 민무늬 / 빗살 / 점 / 창살
- `data/messages.json` — 결과 문장 재료 (성향별 문장, 소중한 것, 필요한 것, 한마디)

## 동작 규칙
- 출제: 아직 덜 나온 갈래에서 먼저, 그 안에서 무작위. 답한 질문은 다시 안 나옴
- 결과: 성향별로 **"그 성향을 고를 수 있었던 질문 중 실제로 고른 비율"** 로 순위. 1·2위(3위가 2위와 비슷하면 3위까지) 사용
  - 이유: 현재 질문 은행은 성향별 선택지 수가 고르지 않음 (자유 26 · 관계 24 · 쉼 23 · 성장 18 · 안정 18 · 성취 11). 단순 횟수로 세면 성취는 거의 1위가 될 수 없음
- 조각보 모양: 조각보마다 시드로 사각형을 나눠 크기가 조금씩 다른 30칸을 만듦 (같은 조각보는 늘 같은 모양)

## 구조
```
index.html, css/style.css
js/core.js    배치·출제·집계·결과 문장 (화면과 무관, 테스트 대상)
js/quilt.js   조각보 SVG
js/share.js   공유 이미지(canvas)
js/app.js     화면·저장·라우팅
data/         질문 은행, 결과 문장
sw.js, manifest.webmanifest, icons/
tests/core.test.mjs   node tests/core.test.mjs
```
